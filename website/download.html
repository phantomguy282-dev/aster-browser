Install in a few steps

  1. Download the installer and compare its SHA-256 with the value shown here using a trusted local hashing tool.
  2. Review the unsigned-publisher notice. Run only a build whose source you trust; do not bypass antivirus protections.
  3. Choose your language and installation location in the graphical wizard.
  4. Launch Aster from your desktop or Start menu. Use Settings to customize it or explicitly import supported browser data.

Requirements

Windows 10 or Windows 11, 64-bit x64 processor, available local disk space and an internet connection for online browsing. Other operating systems and ARM builds are not provided here. No minimum RAM or disk benchmark is asserted.

Unsigned preview. Google OAuth needs developer configuration; VPN needs an existing Windows connection; trusted updates need publisher configuration. Review the privacy policy and terms before use.
