Preview releases

Progress, with
the details attached.

Download metadata comes from the prepared installer. This page describes the expansion direction and its important boundaries; it does not designate a stable channel.

3.0.14 tab navigation patch

Navigate visible tabs with the keyboard

Use arrows appropriate to the tab orientation, or Home and End, while a tab has focus. Collapsed groups stay collapsed and close buttons keep their normal keyboard behavior.

Verified in the installed browser. This focused accessibility improvement does not change signing status or external-service requirements.

3.0.13 security-language patch

Understand site access in your language

Site Control, permission requests and Security Center now translate browser-owned text across eight languages. Website origins and unknown technical diagnostics stay literal.

Verified with real permission requests in the installed browser. Permission choices and private-session separation are preserved. This release remains unsigned.

3.0.12 setup-language patch

Get started in your language

The six-step setup flow, default-browser information and protection settings now support all eight interface languages. Setting values and explicit Windows/import actions remain unchanged.

Verified in the installed browser. Native diagnostics and external-service prerequisites remain documented separately; this release is unsigned.

3.0.11 workspace-language patch

Saved workspaces in your language

Workspace controls, explanations and count messages now support all eight interface languages. Saved workspace names, titles and URLs remain unchanged.

Verified in the installed browser. Native confirmation dialogs retain their documented language limits. This is still an unsigned release candidate.

3.0.10 saved workspaces patch

Return to a set of pages

Save normal website URLs, titles and pin state in the current profile. Reopening asks for confirmation and adds tabs without closing current pages. Private tabs and browser pages are excluded.

Verified in the installed browser. Snapshots do not contain cookies, passwords or page contents. This remains an unsigned candidate.

3.0.9 keyboard activation patch

Close tabs with the keyboard

Focused close buttons now respond to Enter and Space without the parent tab intercepting the action. Existing tab and group keyboard behavior stays intact.

Verified in the installed browser. This remains an unsigned candidate with the same documented service and production-readiness limits.

3.0.8 keyboard-focus patch

Keep your place while using the keyboard

Group headings retain focus when expanded or collapsed, and tab controls retain focus through metadata updates. The address bar keeps focus when it should.

Reproduced and verified in the installed browser. This targeted accessibility repair does not change external-service prerequisites or signing status.

3.0.7 collapsible groups patch

Keep your tab strip focused

Collapse inactive group members without closing their websites. The active tab stays visible; keyboard cycling and tab search keep every page reachable. Normal collapse state survives restart; private state stays temporary.

Verified in the installed browser. Collapsing is organization, not memory-saving suspension. This remains an unsigned release candidate.

3.0.6 profile-language patch

Your profiles, in your language

Profile controls, status messages and explanatory text now support all eight interface languages. User profile names remain unchanged. Verified in the installed application.

This remains an unsigned release candidate. Other localization gaps and external-service prerequisites remain documented.

3.0.5 tab groups patch

Keep related pages together

Name and color your tab groups from the tab context menu. Membership follows normal session restoration, duplicates and reopened tabs. Removing a group leaves its pages open.

Private group metadata stays temporary and separate. This remains an unsigned candidate with the same documented external-service prerequisites.

3.0.4 local profiles patch

Separate spaces for browsing

Create, rename and switch local browser profiles with separate cookies, storage, bookmarks and preferences. Switching requires a confirmed restart. Archiving retains profile files for later restoration.

Verified with generated profiles in real browser processes. Profiles are not separate Windows accounts. This unsigned candidate retains the documented external-service limitations.

3.0.3 efficiency patch

Less repeated work

Repeated state events are batched, unchanged tab controls retain keyboard focus, and tab switching avoids redundant profile writes. Tested measurements verify fewer snapshots and writes, not a claimed overall CPU or RAM percentage.

Security overlays remain immediate. This is an unsigned candidate; external service prerequisites are unchanged.

3.0.2 website zoom patch

A comfortable size for each website

Site Control now saves zoom by hostname for normal browsing. Private zoom is separate and disappears with the private session. Reset returns the website to its default size.

Tested in the installed application. This remains an unsigned candidate with the same documented external-service limitations.

3.0.1 layout patch

Vertical tabs, with room to browse

A saved vertical tab layout keeps your existing tabs and keyboard controls in a left rail. Website content is positioned beside it, and Site Control permission prompts stay above web pages. Switch back to horizontal tabs at any time.

This is still an unsigned candidate. Public deployment and provider integration requirements are unchanged.

3.0 security release candidate

More control, clearer boundaries

Site Control permission prompts, private permission isolation, extension integrity checks, a measurable Security Center, protection levels, first-run/default-browser setup, pinned and searchable tabs, screenshots and window restoration.

This unsigned candidate still needs owner-provisioned signing, hosting and Google authorization. A free VPN provider connection has not been verified. New interface sections are not fully localized. No public deployment or production-readiness claim is made.

0.2 expansion preview

A more personal space for the web

  • Modern domain, port, query, fragment and internationalized URL handling, with no TLD whitelist.
  • Customization Studio with color presets, validated interface CSS, local wallpapers, layout controls and data-only theme sharing.
  • Explicit browser migration and official Google OAuth integration paths.
  • Network filter matching, per-site allowlists and privacy controls.
  • Windows system VPN integration, resource monitoring and experimental unpacked extension management.
  • Signed-metadata update infrastructure and multilingual installer preparation.

Read before upgrading

Google account login needs a registered desktop OAuth client; live consent cannot be assumed. VPN needs a saved compatible Windows connection and does not include servers. Extension API coverage is limited. Updates need a publisher trust key and HTTPS host. The installer remains unsigned. Translation coverage and real-service compatibility should be reviewed in the distribution's verification report.

Full navigation stacks, session-only download lists, proprietary DRM streaming and account sync are not promised. No browsing data should be imported until you explicitly select and authorize it.
