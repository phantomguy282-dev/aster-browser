Preview software

Aster is provided as an early-release browser preview. It may contain defects and is not presented as production-hardened, independently security-audited, or equivalent in maturity to established browsers. Back up your data and evaluate the build before relying on it for sensitive tasks.

No service entitlement

The application does not provide a VPN subscription, Google service entitlement, hosted synchronization, universal extension compatibility or guaranteed streaming support. Third-party services require their own accounts, terms, configuration and potentially payment.

Security and updates

The preview installer is unsigned. There is no promised update schedule or production update host in this distribution. Do not disable OS security checks to install it. Review release provenance and checksums, keep current backups, and use only trusted extensions and themes.
